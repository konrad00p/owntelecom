# 📱 OwnTelecom - System Telekomunikacyjny dla Minecraft

Plugin na serwery **Spigot/Paper 1.20.4** dodający zaawansowany system telekomunikacyjny.

## 🚀 Funkcje

- 📡 **Stacje bazowe** (2G/LTE/5G) z zasięgiem i awariami
- 📞 **Połączenia telefoniczne** i SMS między graczami
- 🌐 **Internet** z przeglądarką stron (książki Minecraft)
- 🛒 **E-commerce** - sklepy online i globalny rynek (Allegro)
- 🏢 **Operatorzy** - twórz własne sieci komórkowe
- 📦 **Pakiety subskrypcyjne** (minuty, SMS, internet)
- 🤝 **Umowy roamingowe** między operatorami
- 🐦 **Social Media** (Twitter)
- 💰 **Płatności Vault** - pełna integracja z ekonomią

## 📥 Instalacja

1. Pobierz plik `.jar` z [zakładki Releases](https://github.com/TWOJA_NAZWA/OwnTelecom/releases)
2. Wrzuć plik do folderu `plugins/` na serwerze
3. Zainstaluj [Vault](https://www.spigotmc.org/resources/vault.34315/)
4. Zrestartuj serwer

## 🎮 Komendy

| Komenda | Opis |
|---------|------|
| `/telefon info` | Stan konta i pakietów |
| `/telefon pakiety` | Dostępne oferty |
| `/call <gracz>` | Zadzwoń do gracza |
| `/sms <gracz> <treść>` | Wyślij SMS |
| `/odbierz` | Odbierz połączenie |
| `/rozlacz` | Rozłącz |
| `/112 <treść>` | Numer alarmowy |
| `/operator utworz <ID> <Nazwa>` | Utwórz operatora |
| `/stacja utworz <op> <tech>` | Postaw stację |
| `/internet` | Otwórz przeglądarkę |
| `/allegro` | Globalny rynek |
| `/umowa zaproponuj` | Zaproponuj umowę |
